Open v0.7 and export your backup first. Host the five app files together in the same directory on a static HTTPS host. Open the hosted index.html in Chrome, wait for offline readiness, then use Install app / Add to home screen. Restore the backup. Do not upload personal backups to the host. Keep the same origin and path in future releases, and increment the service worker cache version. Browser storage is not encrypted by this app and can be cleared. Test install, offline launch and backup restore before relying on it. This is a deployment package, not an APK.
